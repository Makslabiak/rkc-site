# Annotator

Визуальный инспектор для сбора правок по сайту прямо на странице —
без переключения в код, без скриншотов со стрелочками.

## Подключение

Скопируй `annotator.js` в проект и добавь одну строку перед `</body>`:

```html
<script src="annotator.js"></script>
```

Файл самодостаточный: без зависимостей, без сборки, ничего не
конфликтует с CSS сайта (вся панель живёт в Shadow DOM).

## Как пользоваться

- **Cmd+B** (Mac) / **Ctrl+B** (Win/Linux) — включить/выключить режим
  инспектора
- Наведи на любой элемент — увидишь тег, классы, размер, padding,
  margin, шрифт
- Клик по элементу — открывает окно для комментария
- Сохранённые правки остаются на странице лаймовыми метками с
  номером (видны и вне режима инспектора — чтобы не отмечать одно
  и то же дважды)
- Клик по существующей метке — редактирование или удаление
- Панель снизу справа можно **перетащить** за заголовок в удобное
  место — позиция запоминается между перезагрузками. Двойной клик по
  заголовку — вернуть в угол по умолчанию.
- Кнопка **«Скопировать всё»** в панели снизу справа — копирует все
  накопленные правки по всем страницам сайта одним текстом, готовым
  для вставки в чат с Клодом
- Для `<p>` и `<h1>`–`<h6>` при наведении дополнительно показывается
  сам текст элемента (`<p class="...">текст</p>`) и, если получится
  найти совпадение в исходном HTML, номер строки

## Номер строки на file:// (без локального сервера)

Номер строки инструмент определяет через исходный текст HTML-файла.
На `http(s)` это происходит само собой (`fetch()` страницы). На
`file://` (сайт открыт двойным кликом по `index.html`) браузеры
блокируют `fetch()` — вместо этого в панели снизу справа появляется
кнопка **«📄 Подключить файл»**. Нажми её один раз, выбери свой
`index.html` в системном диалоге — и всё, номера строк заработают.

В Chrome/Edge выбор запоминается (через File System Access API +
IndexedDB) — при следующих открытиях страницы файл подключается
сам, без повторного диалога. В Firefox/Safari (там нет этого API)
выбирать файл придётся заново при каждой перезагрузке страницы, но
локальный сервер всё равно не нужен.

Если файл не подключён, текст и остальные параметры элемента при
наведении всё равно работают — недоступен только номер строки.

### Альтернатива: локальный сервер

Если по какой-то причине выбор файла не подходит, рядом лежит
`serve.sh` — старый способ:
```bash
./serve.sh
```
Поднимает сервер (`npx serve`, либо `python3 -m http.server` как
запасной вариант) и выводит адрес — обычно `http://localhost:8000`.
Открывай сайт по этому адресу вместо двойного клика по файлу.

## Хранение

`localStorage` текущего домена, ключ `annotator:comments` — сами
правки. `IndexedDB` (`annotator-fs`) — на file:// хранит хэндл на
выбранный HTML-файл, чтобы не спрашивать его заново при каждой
перезагрузке. Ничего не уходит за пределы браузера — ни на сервер,
ни куда-либо ещё.

## Важно

Это инструмент для этапа разработки. Перед сдачей клиенту или
публикацией на боевой домен — убери строку подключения скрипта,
иначе метки и панель будут видны обычным посетителям сайта.
