# РКС-НР — адаптивная вёрстка

Статическая HTML/CSS/JS-реализация главной страницы по макету Figma. Контрольные размеры: 1920, 768 и 375 px.

## Локальный запуск

```bash
python3 -m http.server 4173
```

После запуска открыть `http://localhost:4173/`.

## Интеграция в Bitrix

- Общая шапка с desktop-навигацией и мобильным меню вынесена в `includes/site-header.php`. В шаблоне Bitrix подключайте её один раз через `include`, предварительно задав `$sitePage` (`home`, `services`, `documents` или `contacts`).
- Страница юридических документов собрана в `documents.html` с вкладками политики обработки персональных данных и пользовательского соглашения. Повторяемые `.document-section` можно заменить на шаблон/компонент Bitrix.
- Детальная страница новости собрана в `news-detail.html`; карточка новости от 02.02.2026 ведёт на неё. Адаптивные правила находятся в `news-detail.css`.
- Страница контактов собрана в `contacts.html`; форму `.contact-form` можно заменить на компонент веб-форм Bitrix, сохранив имена полей и состояния `.is-error`.

- На этапе разработки подключён визуальный инспектор `annotator-tool — копия/annotator.js` (`Cmd+B` / `Ctrl+B`). Перед публикацией на production строку его подключения в `index.html` необходимо удалить.
- Шапка и подвал размечены отдельными блоками `header` / `footer`.
- Контентные сущности (проекты, услуги, новости) представлены повторяемыми карточками и готовы к замене на циклы компонентов Bitrix.
- Все изображения, SVG и шрифты находятся локально в `assets/`.
- Bayer-dither автоматически применяется к прямому дочернему изображению блоков `.image-tone`; источник hero задаётся атрибутом `data-dither-src` у `.hero__media`.
- Если изображения будут загружаться с другого домена, сервер изображений должен разрешать CORS, иначе браузер не даст обработать их через canvas.
- Ссылки-заглушки `href="#"` следует заменить URL и данными инфоблоков на этапе интеграции.
- Кнопку видеоблока следует связать с итоговым видео или медиакомпонентом Bitrix.
