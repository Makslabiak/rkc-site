# Dither 1 — исходный эффект

Зафиксирован исходный вариант photo-dither до экспериментов с новым пресетом.

Источник исходного алгоритма: git-коммит `cce6e7c` (`HEAD` на момент сохранения).

Параметры исходного варианта:

- Bayer matrix: 8×8;
- размер блока по умолчанию: 3 px;
- DPR: максимум 2;
- bias: `0.08`;
- цвет чернил: `#082554`;
- цвет бумаги: `#D7F0FF`;
- бинарный threshold-режим;
- исходные индивидуальные значения `data-dither-block` для страниц сохранены в исходном коммите.

Чтобы вернуть именно исходную реализацию, ориентир — `script.js` и `styles.css` из коммита `cce6e7c`. Файл создан как именованный эталон и не подключается к странице.
